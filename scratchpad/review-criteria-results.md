## Реализация

- Совместимое поле StageResult.criteria = 11, версия протокола 12 без изменения.
- Нумерованный reviewPrompt, строгие маркеры CRITERION, последняя запись на номер, неизвестные номера игнорируются. Notes маскируются.
- Статусы критериев с reviewer/pass в JSON задачи. При входе в новый review отметки сбрасываются, включая старые runner без отчёта. JSON null у старых задач сохранён совместимым.
- Критерии и вердикт запуска записываются атомарно; задача блокируется до запуска, поздний/закрытый pass не принимается. FAIL монотонен внутри pass, даже если два участника работают на одном runner.
- Проверка FAIL, текст причины и claim исхода review выполняются одной транзакцией. require:any не перекрывает FAIL, после claim нет дополнительного чтения, способного потерять переход при ошибке.
- Консоль: ok/fail/не проверен, причина FAIL, безопасный раскрываемый текст timeline кроме session.step. Старое ok=true без status не считается новой проверкой.
- Тестовая инфраструктура использует native fake-llm, устаревшее упоминание fake-agent в OpenSpec исправлено.
