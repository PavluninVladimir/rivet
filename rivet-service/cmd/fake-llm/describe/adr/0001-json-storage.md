## Контекст

CRM работает одним процессом Node.js без внешних зависимостей, данных у отдела продаж немного. Хранилище в `server/storage/json-store.js` держит контакты в памяти и пишет их в `data/crm.json`.

## Решение

Хранить контакты одним JSON-файлом. Запись атомарная: данные пишутся во временный файл рядом и переименовываются поверх основного. Операции изменения идут через очередь по одной.

## Последствия

- Нет внешней базы, установка и запуск одной командой.
- Запись сериализуется, несколько процессов с одним файлом работать не могут.
- Поиск и постраничная выдача идут по массиву в памяти.

## Рассмотренные варианты

- SQLite (`node:sqlite`): экспериментальный модуль в используемой версии Node.js.
- PostgreSQL: отдельный контейнер ради небольшого объёма данных.
