## Контекст

Интеграционные Go-тесты уже покрывают границу сервис плюс база (планировщик, конвейер на фейковом runner'е и фейковом SCM). Непокрытым остаётся путь через браузер: консоль, SSE, действия человека. Бэкенд лёгкий (один бинарник плюс compose), runner принимает произвольную команду агента, поэтому честный e2e у нас дешёвый.

## Цели / Не-цели

**Цели:** автоматическая проверка реальных сценариев пользователя через браузер против настоящего rivetd и Postgres.

**Не-цели:** e2e с настоящим Claude или настоящим GitHub, нагрузочные тесты, визуальная регрессия по скриншотам.

## Решения

- **Пирамида тестов зафиксирована.** Юнит: доменные статусные машины. Интеграционные: сервис плюс база, Go, без браузера. E2E: браузер, сервис, база, Playwright. Слои не дублируют друг друга: e2e проверяет только то, что видно пользователю.
- **Настоящий бэкенд вместо мока API.** Мок проверял бы вёрстку, а самые ценные регрессии живут в связке UI и конвейера. Цена реального бэкенда у нас минимальна.
- **Агент - скрипт-заглушка** через существующий `RIVET_AGENT_CMD`: делает фиктивный коммит и выводит нужные маркеры (`VERDICT: APPROVED`, `BLOCKED: вопрос`). Детерминированно, быстро, без токенов.
- **SCM - fake-провайдер за флагом `RIVET_SCM=fake`** в rivet-service. Интерфейс `scm.Adapter` уже есть, фейк повторяет реализацию из интеграционных тестов: фиктивный PR-URL, merge как no-op. По умолчанию флаг выключен.
- **Изоляция данных:** каждый прогон получает чистую тестовую базу (паттерн одноразовых баз из Go-тестов, через `RIVET_DATABASE_URL`).
- **Ожидания по состоянию, не по времени.** Никаких sleep в тестах, только web-first assertions Playwright по видимым статусам. SSE делает изменения видимыми без перезагрузки, это часть проверки.

## Риски / Компромиссы

- [Флаки на SSE и таймингах] - ожидания по состоянию, ретраи Playwright, трейсы в артефактах CI для разбора.
- [Fake SCM разойдётся с реальным GitHub-адаптером] - fake реализует тот же интерфейс `scm.Adapter`, контрактные детали GitHub остаются на интеграционном уровне и dogfooding-прогонах.
- [Рост времени CI] - job параллелен основному, три сценария укладываются в пару минут.
