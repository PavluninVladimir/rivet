## Контекст

Есть эталонный прототип (вёрстка, токены oklch, слоевой алгоритм DAG, демо-данные) и работающий API v1 (REST + SSE). Мотивация — см. proposal.md.

## Цели / Не-цели

**Цели:** консоль поверх живого API, максимально переиспользующая прототип; один бинарник для self-hosted.

**Не-цели:** лента сессий людей (ждёт бэкенда team-visibility), Usage-аналитика сверх сводной таблицы, Settings (нечего настраивать), аутентификация (dev-заголовок X-Rivet-User).

## Решения

- **Vite + React + TypeScript, без UI-библиотек.** Прототип даёт готовую вёрстку и токены — компонентные библиотеки только мешали бы переносу. Альтернатива (Next.js) отвергнута: SSR не нужен, консоль — SPA за API.
- **Данные: тонкий fetch-слой + один SSE-поток на проект, без стейт-менеджера.** События SSE инвалидируют/патчат локальный стор (React context + useReducer). Альтернатива (TanStack Query) отвергнута для среза: SSE-инвалидация покрывает нужды, меньше зависимостей.
- **DAG — перенос слоевого алгоритма прототипа** (слои по глубине зависимостей, SVG-рёбра Безье, пан/зум трансформом) в React-компонент. Критический путь считается на клиенте по оценкам задач.
- **Dev — Vite-proxy на rivetd (:8181), prod — go:embed.** CORS не нужен ни там, ни там. Раздача: `rivetd` отдаёт `/` из встроенной сборки, `/api/*` — как раньше.
- **Русский UI** — язык проекта.

## Сверка с дизайн-прототипом

Переносятся как есть: токены и статусные цвета, сайдбар/топбар, дашборд Epic (прогресс, чипы, attention, DAG+список, фильтры, критический путь), деталка-drawer, палитра ⌘K, таблицы списков. Отклонения: данные живые (демо-данные прототипа не переносятся); блок Usage — сводная таблица вместо панелей прототипа; Settings и лента команды — отложены (не-цели).

## Риски / Компромиссы

- [SSE-обрыв теряет live-лог] → по контракту session.log не реплеится; события доигрываются по Last-Event-ID, лог продолжается с момента переподключения.
- [go:embed требует Node в сборке rivetd] → сборка консоли отдельным шагом Makefile; embed принимает и пустую директорию (UI просто не раздаётся).
