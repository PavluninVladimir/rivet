## Purpose

Определяет наблюдаемость Rivet: append-only event log всех действий и учёт usage (токены, стоимость, время) в разрезе Epic, задач и runner'ов. В любой момент видно, что происходит и сколько это стоит.

## ADDED Requirements

### Requirement: Event log всех действий

Каждое значимое действие ДОЛЖНО записываться в event log: время, субъект (runner, scheduler, system, human), тип события (start, test, review, fail, block, pr, merge и т.п.), затронутая задача, Epic и проект, человекочитаемое описание. Лог ДОЛЖЕН быть append-only: записи не изменяются и не удаляются.

#### Scenario: Лента активности

- **WHEN** пользователь открывает раздел Activity
- **THEN** он видит хронологическую ленту событий по всем проектам с фильтрацией по проекту, Epic, задаче и типу события

#### Scenario: Восстановление хода задачи

- **WHEN** пользователь открывает timeline задачи
- **THEN** он видит полную историю её событий (старт, проверки, замечания review, исправления) с отметками времени

### Requirement: Учёт usage

Система ДОЛЖНА учитывать израсходованные токены, стоимость и длительность по каждой задаче и агрегировать их по Epic, проекту, runner'у и модели за период.

#### Scenario: Стоимость Epic

- **WHEN** пользователь открывает Epic
- **THEN** он видит суммарные токены, стоимость и затраченное время Epic, а по каждой задаче — её вклад

### Requirement: Live-наблюдение за задачей

Для выполняющейся задачи система ДОЛЖНА показывать текущие шаги агента (что он делает сейчас) и вывод выполняемых команд в реальном времени.

#### Scenario: Наблюдение за выполнением

- **WHEN** пользователь открывает выполняющуюся задачу
- **THEN** он видит поток шагов агента и терминальный вывод текущей команды без ручного обновления страницы
