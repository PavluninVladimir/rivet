## Зачем

Консоль проверяется только глазами, а связка UI, SSE и конвейера самая хрупкая часть системы. Нужны автоматические e2e-тесты, которые гоняют реальные пользовательские сценарии через браузер против настоящего сервиса.

## Что меняется

- Фиксируется пирамида тестов: юнит-тесты на домен, интеграционные на границе сервис плюс база (существующие Go-тесты), e2e полным путём браузер, сервис, база через Playwright.
- В `rivet-web` появляются Playwright-тесты: smoke, полный цикл задачи до merge кнопкой, эскалация с ответом через UI, проверка live-обновлений по SSE.
- В `rivet-service` появляется fake-провайдер SCM за флагом окружения, чтобы конвейер в тестах не ходил в GitHub. Роль агента играет скрипт-заглушка через существующий `RIVET_AGENT_CMD`, без Claude и токенов.
- В CI добавляется job e2e с артефактами (трейсы и скриншоты при падении).

Поведение продукта не меняется, это тестовая инфраструктура (`skip_specs: true`).

## Затронутые репозитории

- [x] `rivet` (rivet-service) - fake SCM за флагом, без изменений продуктового поведения

- [ ] `rivet-android`
- [ ] `rivet-ios`

## Impact

- Новая dev-зависимость `@playwright/test` в rivet-web.
- CI дольше на пару минут за счёт job e2e.
- Флаг `RIVET_SCM=fake` доступен только как явная настройка окружения, по умолчанию поведение прежнее.
